# Cupoftea.social for Android

The Android app for [Cupoftea.social](https://cupoftea.social), a wholesome and positive Mastodon community first launched in 2022.

You can download the APK from the [Releases section](https://github.com/WhiskeyOmega/Cupofteasocialapp/releases/latest).

## About

Cupoftea.social is a Mastodon server. This app is a fork of the [official Mastodon Android app](https://github.com/mastodon/mastodon-android), restyled and adjusted for the Cupoftea.social community.

Cupoftea.social is not affiliated with or endorsed by Mastodon gGmbH. The Mastodon name and logo are trademarks of Mastodon gGmbH.

## Features

- Chronological home timeline with no algorithms or ads
- Follow people and hashtags, and discover new accounts
- Post with polls, images, videos and content warnings
- Lists and word filters to curate what you see
- Multiple accounts, light and dark themes, and QR code profile sharing

## Building

The app uses Java 17 features, so you need JDK 17 or newer to build it. You can import the project into Android Studio and build it from there, or run this command in the project directory:

```shell
./gradlew assembleRelease
```
